# Controle de despesas

Aplicativo em Java para registrar despesas, listar itens e visualizar o total gasto.

## Requisitos

- Java JDK 17 ou superior

## Como executar

No Windows, basta executar:

```bat
run.bat
```

Ou manualmente:

```bat
javac "Controle de despesas\ControleDespesas.java"
java -cp "Controle de despesas" ControleDespesas
```

## Menu

1. Adicionar despesa
2. Listar despesas
3. Mostrar total gasto
4. Sair
